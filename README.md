# 🤖 AI News Summarizer

An AI-powered news summarization web application built using Django, NewsAPI, and Google Gemini AI.

## Features

* Search news by keyword
* Browse news by category
* AI-generated summaries using Gemini AI
* News images and article links
* SQLite database storage
* Django Admin Panel
* Responsive UI

## Tech Stack

* Python
* Django
* Bootstrap
* NewsAPI
* Google Gemini AI
* SQLite

## Installation

```bash
git clone <repository-url>
cd AI-News-Summarizer

python -m venv venv
venv\Scripts\activate

pip install -r requirements.txt

python manage.py migrate
python manage.py runserver
```
